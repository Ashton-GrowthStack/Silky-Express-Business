## 🎯 HOW TO SCORE RESPONSES

**Scoring System (0-100):**

```
CATEGORY 1: PRODUCT QUALITY (25% weight)
- Accuracy specification: 0-10 points
- Features match requirements: 0-10 points
- Warranty/support: 0-10 points
→ Subtotal × 0.25

CATEGORY 2: PRICE (20% weight)
- Competitive pricing: 0-10 points
- Clear pricing breakdown: 0-10 points
- Value for money vs competitors: 0-10 points
→ Subtotal × 0.20

CATEGORY 3: RELIABILITY (20% weight)
- Years in business: 0-10 points
- Reference quality: 0-10 points
- South Africa experience: 0-10 points
→ Subtotal × 0.20

CATEGORY 4: COMMUNICATION (15% weight)
- Response time: 0-10 points
- Professionalism: 0-10 points
- Clarity of answers: 0-10 points
→ Subtotal × 0.15

CATEGORY 5: LOGISTICS (20% weight)
- Lead time acceptable: 0-10 points
- DDP available: 0-10 points
- South Africa support: 0-10 points
→ Subtotal × 0.20

FINAL SCORE = Sum of all weighted subtotals (Max 100)
```

**EXAMPLE SCORING:**

```
JIANGSU FARFLY DETAILED SCORING:

PRODUCT QUALITY (25%):
```

## 📋 RED FLAGS DETECTION EXAMPLES

**If you see these in responses, mark as RED FLAG:**

```
🚩 RED FLAG #1: Vague Specifications
Response says: "High accuracy" or "Premium quality"
Should say: "±0.05ml accuracy" or "99.5% consistency"
ACTION: Ask for exact specifications in writing

🚩 RED FLAG #2: Hidden Costs
Response says: "Quote includes freight"
But doesn't itemize customs, duties, local delivery
ACTION: Request itemized breakdown to Durban

🚩 RED FLAG #3: No References Available
Response says: "References available upon request" but doesn't provide names
ACTION: Request 3 specific reference contacts immediately

🚩 RED FLAG #4: Poor Communication
Response has grammar errors, unclear answers, doesn't address your questions
ACTION: Downgrade score - this affects support quality

🚩 RED FLAG #5: No South Africa Experience
Company has never shipped to South Africa or Africa
ACTION: Risk factor - additional logistics complexity

🚩 RED FLAG #6: Unclear Payment Terms
Response doesn't state 50/50, 30/70, or other split
ACTION: Request clear payment schedule before proceeding

🚩 RED FLAG #7: Too Good to Be True
Price is 70% less than competitors with same specs
ACTION: Verify references + ask why so cheap
```
